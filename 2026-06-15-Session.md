# Session 2026-06-15 — Scanner-Bug + Weiterzählen gefixt

Zwei zusammenhängende Bugs gefixt, die dazu geführt haben, dass ShortFlow beim gleichen Thema immer wieder bei Short01 angefangen hat.

## Was gefixt wurde

### Bug 1: Scanner fand keine Shorts
`scanner.py:27` hat `base / "Shorts"` gebaut, aber `output_dir` war bereits `~/Downloads/WTFWissen/Shorts`. Ergebnis: Suche in `…/Shorts/Shorts/` → "Keine Shorts gefunden".

**Fix:** `shorts_root = base` statt `base / "Shorts"`.

### Bug 2: Brain nummerierte immer ab Short01
`brain.py:generate_table()` hatte keinen `start_num`-Parameter. Die Nummerierung lief immer ab `i+1 = 1`.

**Fix:**
- `generate_table()` bekommt `start_num: int = 1`
- `brain_tab.py` liest `scan_result.next_short_num` und übergibt es
- `app.py` gibt `get_scan_result` als Callable an `BrainTab`

## Ergebnis

Statusleiste zeigt nach Fix korrekt: `✓ Projekte: 1 · ✓ Shorts: 123 · ✓ Nächster Short: Short147`

App rebuilt und auf Desktop deployed.
